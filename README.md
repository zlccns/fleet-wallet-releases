# Robinhood Batch Trader — Downloads

Robinhood Batch Trader 桌面应用的安装包与签名更新发布入口。

## 下载

安装包将在 [Releases](https://github.com/zlccns/robinhood-batch-trader-releases/releases) 发布。当前尚未发布可下载版本。

应用提供本地钱包管理、资产查询、批量资金与 DEX 交易。当前桌面目标为 macOS；本项目与 Robinhood 无隶属或官方背书关系。

## 应用内更新

在应用“设置 → 版本与更新”中检查新版本、下载并验证签名，再确认安装重启。发布验收完成且签名更新配置生效后，此入口才可用于更新。

本仓库只存放公开发布说明及 Release 附件，包括安装包、签名和 latest.json；源码在独立私有仓库维护。不要上传用户钱包、私钥、助记词、密码、数据库、备份或发布签名私钥。
